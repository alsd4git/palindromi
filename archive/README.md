# Materiale storico

Questa cartella conserva i file di lavoro e l'acquisizione Wayback del 31 marzo
2019 del sito originale `http://plgrs.lacab.it/palindromi/`.

- `extraction/` contiene la tabella HTML acquisita e il testo estratto prima
  della correzione manuale.
- `wayback-2019/` è una copia storica, inclusi script e risorse di terze parti
  salvati con la pagina. Non fa parte del sito pubblicato e non va eseguita o
  ridistribuita come applicazione corrente.

La raccolta che alimenta il sito attuale è `../docs/data/palindromes.txt`.
